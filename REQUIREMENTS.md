# Requirements

## R

- R >= 4.4.1
- `cmdstanr` >= 0.9.0 (with a working CmdStan installation)
- `tidyverse` >= 2.0.0
- `posterior` >= 1.6.1
- `bayesplot` >= 1.14.0

Install CmdStan via:
```r
cmdstanr::install_cmdstan()
```

## Python

- Python >= 3.9
- `torch`, `xgboost`, `scikit-learn`, `pandas`, `numpy`, `shap`

```bash
pip install torch xgboost scikit-learn pandas numpy shap
```
